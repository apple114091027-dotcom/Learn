# 知識迷宮｜史料探險・認知摩擦任務版

GitHub Pages 靜態網站。

## 發布
1. 將這個資料夾中的 `index.html`、`.nojekyll`、`README.md` 上傳到 Repository 根目錄。
2. 到 Settings → Pages。
3. Source 選 Deploy from a branch；Branch 選 main；Folder 選 /(root)，然後 Save。

## 新增的認知摩擦任務
- 直覺陷阱：檢查照片能支持多大範圍的結論。
- 矛盾線索室：比較虛構的照片註記、口述回憶與紀念冊記載，練習交叉比對。
- 觀點修正工作台：留下替代解釋、自我檢核與信心前後紀錄。

注意：矛盾線索室中的日期與人物為教學用虛構資料，不代表本文史實。此版本未連接 AI API；紀錄只存在目前瀏覽器的 localStorage。
